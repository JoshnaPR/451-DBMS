## Work Summary
For Sprint 2, we worked on Module 3 of the Meta Engineering Capstone Project on Coursera. The main features we worked on were the Data Visualization and Database Client. For each of these features, there were multiple tasks to be completed. Data Visualization consists of the following tasks: connecting our database in the excel sheet and filtering the data, creating data fields for the first and last names, create data field that stores sales profit, creating a bar chart, creating a line chart, create bubble charts, comparing sales of 3 cuisines, and combining the bar and buuble chart. The Database Client consists of the following tasks: installing Python, installing Jupyteer Notebook, establishing a connection between Python and our database, extend the environment, query the database to show all tables and print results, and query the table to print customers who spent more that $60.
